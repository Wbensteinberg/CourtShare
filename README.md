# CourtShare Project Brief 

CourtShare, a private tennis court rental platform. Think Airbnb or Swimply but for tennis courts. It allows players to find and book private tennis courts by the hour, and lets court hosts list their available courts, manage bookings, and receive payments.

## 🛠️ Tech Stack
- **Frontend:** Next.js (App Router) + Tailwind CSS + TypeScript
- **Backend:** Firebase (Auth, Firestore, Storage)
- **Payments:** Stripe (Checkout + Connect)

## 🔑 Core Features
- Login via Google
- Court browsing + filtering
- Stripe integration for booking payments
- Player dashboard (upcoming bookings)
- Court listing form (images, location, price, availability)
- Booking calendar with time slots
- Host dashboard (see bookings, manage courts)

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
